# 유안나 · 유선 안전 나눔 (V35)

현장에서 폰으로 360° 촬영하면 맨홀·전력선·건설장비·고소작업차·도로/차량속도 등을 **폰 내부에서** 분석해 위험성 평가표를 자동 체크합니다.
영상과 사진은 녹화·저장·업로드하지 않습니다.

- 사용 주소: https://savior3631-web.github.io/risk-ai/
- 데모(가상 분석): https://savior3631-web.github.io/risk-ai/?aidemo=1
- AI 모델은 처음 1회 약 150MB를 다운로드한 뒤 폰에 저장합니다 (Wi-Fi 권장)
- AI는 위험요인만 체크하고, 안전대책은 작업자가 직접 체크합니다

## 탭 구성
- **홈**: 360° 현장 스캔, 위치·날씨, 최근 기록
- **평가표**: 현장 위험성 평가표(전송) 작성·이미지 저장
- **복구현장**: 사진으로 환경·해소방안 초안 작성 → 텍스트 복사·보고 이미지 저장·카톡/Teams 공유
- **기록**: 폰 안에 최근 20건 보관
- **안나 키우기**: 잘못 찾은 대상을 사진과 함께 제보 (강남전송운용팀 최명락)
- **TBM 체크리스트**: 5개 구분 완료 체크 → 날짜·시간 표시 → Teams 사진 등록

## AI 구성 (2개 모델)
- `equip.onnx` (약 15MB): 장비·차량·사람 탐지 (YOLOE-11s + 현장 사진 학습, 42개 항목)
  - 포크레인·고소작업차·크레인·덤프·로더 등 중장비
  - 아웃트리거·받침대·고임목, 컬러콘·입간판·에어로봇·신호깃발·소화기
  - 송풍기·배풍기·가스측정기, 맨홀, 전주보호판, 철탑·중계기·장비함, 차량 접근금지 표지
  - 차량·사람·안전모
- CLIP (처음 1회 다운로드): 장면 판단 — 도로/골목/옥상/실내/교량, 물기·결빙, 전력선·통신선
- 라이선스 주의: YOLOE(Ultralytics)는 AGPL-3.0입니다. 사내 APK 정식 배포 전 라이선스 검토 또는 Apache 계열 모델로 교체가 필요합니다
