- `equip.onnx` (약 15MB): 장비·차량·사람 탐지 (YOLOE-11s, 21개 항목: 포크레인·크레인·덤프·지게차·고소작업차·롤러·로더·펌프카·시저리프트·사다리·컬러콘·맨홀·잔해·차량·사람)
- CLIP (처음 1회 다운로드): 장면 판단 — 도로/골목/옥상/실내/교량, 물기·결빙, 전력선·통신선
- 라이선스 주의: YOLOE(Ultralytics)는 AGPL-3.0. 사내 APK 정식 배포 전 라이선스 검토 또는 Apache 계열 모델로 교체 필요
